# Frontend Development Skill

Read the slice packet and Selenium tests. Implement only the current UI slice against documented API contracts. Run the focused Selenium suite, fix failures, verify accessibility and responsive behavior, then create a focused commit after passing. Push only with explicit approval, never force-push, and never include unrelated files.
