# Frontend Planning Skill

Read the frontend, API, authentication, and security specifications. Produce one UI slice packet with route/view, user states, API calls, authorization visibility, loading/error/empty behavior, accessibility criteria, Selenium scenarios, allowed paths, and forbidden paths. Do not implement or run browser commands.
